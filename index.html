      - open_pr(team="@sre")

Quickstart

Deploy in 3 commands

Install via Helm, connect your Prometheus, and PulsarOps starts learning your baseline in minutes.

install.sh
# 1 — Install the Helm chart
$ helm repo add pulsarops https://charts.pulsarops.dev
$ helm install pulsarops pulsarops/pulsarops-agent \
    --set apiKey=$PULSAR_API_KEY \
    --set model=mimo-v2.5-pro

# 2 — Verify connectivity
$ pulsarctl status
✓ Agent connected · 3 pods healthy
✓ Prometheus detected · 847 metrics ingesting
ask.sh
# Ask natural-language questions
$ pulsarctl ask "why is api-gateway slow?"

FAQ

Common questions

How does PulsarOps differ from PagerDuty or Datadog?

PagerDuty alerts you. Datadog shows you charts. PulsarOps detects, diagnoses, and fixes — generating PRs, rollbacks, and post-mortems automatically. It's the difference between a smoke alarm and a fire sprinkler.

Can the agent break my production environment?

Only within guardrails you define. Set blast-radius limits (max scale-out, allowed namespaces, budget caps) and approval gates. Every action is logged and one-click reversible.

What models does PulsarOps use?

MiMo Pro (default for anomaly classification and action planning), Claude Sonnet (incident reports), DeepSeek (cost analysis). Bring your own model via OpenAI-compatible endpoint.

How long until it learns my baseline?

Typically 24–48 hours of metric history for basic anomaly detection. Richer remediation patterns improve over 1–2 weeks as the agent observes your deploy frequency and traffic patterns.
